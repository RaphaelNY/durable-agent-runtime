# 0001：学习优先，手写实现

- 日期：2026-10-26
- 状态：接受

## 背景

这个项目的第一目标是学习，第二目标是作为面试可讲的个人项目。作者已有正式工作，时间不是硬约束，但希望每一行核心代码都能解释。agent 可以快速生成完整实现，但阅读 agent 写的代码比自己做更难学会，而且看 PR 的速度跟不上生成速度。

## 选项

1. **让 agent 生成完整实现**：快，但作者无法解释每一行，面试一问就露馅。
2. **从零手写，不留任何脚手架**：学习效果最好，但会把时间花在样板代码和依赖选型上。
3. **先设计契约，再手写实现**：主目录只保留契约、测试和设计文档；agent 只做 review 和方案讨论。

## 决定

采用方案 3：

- P0 先定事件 schema、journal 分帧、checkpoint、恢复语义；契约定稿前不写 engine。
- 核心代码由作者手写；agent 默认进入导师模式（见 `AGENTS.md`）。
- 每个阶段可停可交付；HNSW 放最后，允许降级为暴力索引。

## 后果

- 进度比 agent 生成慢；总周期按 20–27 周估。
- 需要接受"先写文档/测试，再写实现"的节奏。
- 好处是每一行都能在面试里解释，失败和取舍本身也成为面试素材。
- 旧方向（SecureAgent Runtime）的代码和文档保留在 `archive/`，不参与新项目。
